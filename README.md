# Operation: Make You Smile 💗

A cute multi-screen interactive love website made with vanilla HTML, CSS and JavaScript. No build step or dependencies.

## Pages / screens
- Welcome screen with floating sparkles and a “busy” prank button
- Mission briefing screen with playful chat bubbles
- Main question with runaway No button, random reactions and crying bear
- Secret gift / silly certificate
- Final celebration with hearts and replay

## Effects
- Responsive, touch-friendly design
- Animated background sparkles and floating hearts
- No button runs away from mouse/touch attempts and changes its dramatic reactions
- Heart bursts, tiny click hearts, character wobble and button glow
- Reduced-motion accessibility support

## Personalize
Open `index.html` to edit the names and text. Search for “you cutie” to change the greeting. Edit the messages inside `script.js` (`lines` array) to personalize the No-button jokes.

## Run locally
Double-click `index.html` to open it in a browser.

## Deploy on GitHub Pages
1. Create a GitHub repository (suggested name: `operation-make-you-smile`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, and Save.
5. Wait for deployment; GitHub will show the published URL.
